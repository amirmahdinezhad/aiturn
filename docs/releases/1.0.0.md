# Aiturn 1.0.0

## English

The first release under the complete Aiturn identity, for macOS 12+ on Apple Silicon and Intel.

- Manage AI coding accounts and organize them into workspaces from the menu bar.
- Save and switch Codex and Claude Code accounts, with experimental Antigravity support.
- Read supported usage limits, reset times and menu-bar status.
- Choose light, dark or system appearance and configure each workspace. Keyboard navigation works without focus outlines.
- Review update notes, download, then explicitly choose Install & relaunch.
- Fresh repository history, concise bilingual documentation and an original Aiturn cover.

Open the DMG and drag Aiturn to Applications. Earlier development installations need a manual installation and saved-account reimport into the renamed profile store; provider CLI logins remain intact. Version numbering restarts at 1.0.0. This build is ad-hoc signed and not Apple notarized. If needed, allow first launch in System Settings → Privacy & Security → Open Anyway.

## فارسی

اولین انتشار با هویت کامل Aiturn، برای macOS 12 و جدیدتر روی مک‌های Apple Silicon و Intel.

- مدیریت حساب‌های ابزارهای کدنویسی هوش مصنوعی و گروه‌بندی آن‌ها در فضاهای کاری از نوار منو.
- ذخیره و تعویض حساب‌های Codex و Claude Code، همراه با پشتیبانی آزمایشی Antigravity.
- نمایش محدودیت مصرف، زمان بازنشانی و وضعیت حساب در نوار منو برای سرویس‌های پشتیبانی‌شده.
- تم روشن، تیره یا هماهنگ با سیستم و تنظیمات مستقل هر فضای کاری؛ جابه‌جایی با صفحه‌کلید بدون کادر فوکوس.
- مشاهدهٔ تغییرات و دانلود به‌روزرسانی؛ نصب فقط با انتخاب Install & relaunch.
- شروع تازهٔ تاریخچهٔ مخزن، راهنمای کوتاه دوزبانه و تصویر معرفی اختصاصی Aiturn.

فایل DMG را باز کنید و Aiturn را به Applications بکشید. نسخه‌های آزمایشی قبلی به نصب دستی و واردکردن دوبارهٔ حساب‌های ذخیره‌شده نیاز دارند؛ ورود ابزارهای خط فرمان باقی می‌ماند. شماره‌گذاری از 1.0.0 شروع می‌شود. این نسخه امضای محلی دارد و Apple آن را notarize نکرده است. در صورت مسدودشدن اولین اجرا، از System Settings → Privacy & Security → Open Anyway اجازهٔ اجرا بدهید.
